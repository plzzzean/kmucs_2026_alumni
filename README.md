- **장소**: 국민대학교 체육관

`main` 브랜치에 푸시하면 1~2분 뒤 자동으로 반영됩니다.

## 주차 신청 → 구글 스프레드시트 연결

페이지의 주차 신청 모달에서 **이름 · 전화번호 · 학번(입학연도 두 자리, 예: 25)** 을 받아
구글 스프레드시트에 한 줄씩 저장합니다. 별도 서버 없이 Google Apps Script 웹 앱을 사용합니다.

```
[페이지 모달] --POST--> [Apps Script 웹 앱] --appendRow--> [스프레드시트 '주차신청' 탭]
```

### 1. Apps Script 만들기

1. 신청 내용을 받을 구글 스프레드시트를 엽니다.
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 지우고 [`apps-script/parking.gs`](apps-script/parking.gs) 내용을 붙여넣은 뒤 저장합니다.

> 시트 안에서 만든 스크립트는 자동으로 그 시트에 연결되므로 시트 ID를 코드에 적지 않아도 됩니다.
> 첫 신청이 들어오면 `주차신청` 탭과 헤더(신청시각 · 이름 · 전화번호 · 학번)가 자동으로 생깁니다.

### 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택 옆 ⚙️ 를 눌러 **웹 앱**을 고릅니다. "라이브러리"가 아닙니다.
3. 아래처럼 설정합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고 권한을 승인합니다. "확인되지 않은 앱" 경고가 뜨면 **고급 → 이동**을 누릅니다.
5. 완료 화면의 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> ⚠️ **학교 계정(@kookmin.ac.kr)으로 배포하면 안 됩니다.**
> 학교 Google Workspace에서는 "모든 사용자" 옵션이 막혀 있어서, 국민대 계정으로 로그인하지 않은 사람은 신청이 실패합니다.
> **개인 Gmail 계정**으로 시트와 스크립트를 만드세요. URL에 `/a/macros/kookmin.ac.kr/` 가 들어 있으면 학교 계정으로 배포된 것입니다.

### 3. 페이지에 URL 넣기

[`script.js`](script.js)의 `PARKING_ENDPOINT` 값을 복사한 URL로 바꾸고 `main`에 푸시합니다.

```js
const PARKING_ENDPOINT = "https://script.google.com/macros/s/.../exec";
```

### 4. 동작 확인

배포된 페이지에서 직접 한 번 신청해 보고, 시트에 한 줄이 추가되는지 확인한 뒤 테스트한 줄을 지웁니다.

### Apps Script 코드를 수정했을 때

**배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포** 로 다시 배포합니다.
이렇게 하면 URL이 그대로 유지됩니다. "새 배포"로 하면 URL이 바뀌므로 `script.js`도 함께 바꿔야 합니다.

입력 형식 검사는 `script.js`(페이지)와 `parking.gs`(서버) **양쪽에** 있습니다.
항목이나 형식을 바꿀 때는 두 파일을 같이 고치고, Apps Script도 위 방법으로 다시 배포해야 합니다.

### 참고

- 전화번호와 학번은 앞자리 0이 사라지지 않도록 텍스트로 저장됩니다.
- 웹 앱 URL은 페이지 코드에 공개되므로 누구나 신청 데이터를 **보낼** 수는 있지만, 시트를 **읽을** 수는 없습니다.
- 수집한 개인정보는 동의 문구대로 **행사 종료 후 파기**해 주세요.
