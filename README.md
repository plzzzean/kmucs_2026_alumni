# 슬랑제 : 울림 — 2026 초대장 페이지

국민대학교 소프트웨어융합대학 **슬랑제 : 울림** 행사 초대장 웹페이지입니다.

- **일시**: 2026년 11월 21일(토) 15:00 ~ 19:00
- **장소**: 국민대학교 체육관
- **주최·주관**: 국민대학교 소프트웨어융합대학 · 제10대 소프트웨어융합대학 학생회 ECHO
- **배포 주소**: https://plzzzean.github.io/kmucs_2026_alumni/

빌드 과정이 없는 정적 페이지(HTML/CSS/JS)이고, GitHub Pages로 무료 배포합니다.
`main` 브랜치에 푸시하면 1~2분 뒤 자동으로 반영됩니다.

## 페이지 구성

| 섹션 | 내용 |
|---|---|
| 메인 | 포스터 디자인 기반 SVG 애니메이션 |
| 초대 글 | 학생회 인사말 |
| 일시 | 11월 달력, 행사까지 남은 시간 카운트다운 |
| 프로그램 | 1부 RE:CAP · 2부 RE:IMAGINE 2036 · 3부 KMUCS NIGHT |
| 오시는 길 | 네이버/카카오 지도, 주소 복사, 교통·주차 안내 (주차권은 현장 발급) |
| 푸터 | 초대장 공유하기 (모바일 공유 시트, PC에서는 링크 복사) |

## 파일 구조

```
index.html              페이지 본문
style.css               스타일
script.js               달력·카운트다운·주소 복사·공유 동작
img/                    포스터, 링 이미지 (img/poster.jpg 는 카카오톡 공유 미리보기용)
```

로컬에서 확인할 때는 `index.html`을 브라우저로 열면 됩니다.
